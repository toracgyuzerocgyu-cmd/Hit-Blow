# Hit-Blow

Java で作成した、3桁の数字を当てるコンソールゲームです。

## 概要

コンピューターが生成した3桁の数字を予想し、入力した数字と正解を比較します。
数字と位置が一致した場合を **Hit**、数字のみ一致して位置が異なる場合を **Blow** として表示します。

最大10回まで挑戦でき、3 Hit になるとクリアです。

## 主な機能

- ランダムな3桁の正解数字を生成
- 3桁の数字のみ受け付ける入力チェック
- Hit / Blow の判定
- 最大10回の挑戦回数制限
- 正解できなかった場合の答え表示
- ゲームの再プレイ機能

## 実行方法

```bash
javac -d . HitAndBlow.java
java HitAndBlow.HitAndBlow
```

## 遊び方

1. プログラムを起動する
2. 3桁の数字を入力する
3. 表示された Hit と Blow の数を確認する
4. 最大10回以内に3 Hitを目指す
5. ゲーム終了後、再プレイするか選択する

## 使用技術

- Java
- `Random`：正解数字の生成
- `Scanner`：コンソール入力
- 正規表現：3桁の数字の入力チェック
